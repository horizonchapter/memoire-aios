# Sécurité

Le skill écrit uniquement dans le dossier AIOS que tu lui donnes et n'écrase jamais un fichier existant. Les deux scripts Python n'utilisent que la bibliothèque standard, sans accès réseau. Le skill interdit de noter des secrets (clés, mots de passe) dans le second cerveau.

Un problème de sécurité ? Ne l'ouvre pas en issue publique : utilise **Security → Report a vulnerability** sur la page du dépôt.
